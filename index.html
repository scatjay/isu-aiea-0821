U0

開場：先確認你的工具會動

09:00–09:30

這半小時不教東西，只做一件事：確認你等一下按下去會有反應。裝不起來的人在這裡就要舉手，不要撐到十一點。

核心練習

  1. 打開 Claude 桌面版，登入。
  2. 問它一句：「你現在讀得到我電腦上的檔案嗎？」
  3. 不管它回什麼，把回答看完——你要知道它現在「碰得到什麼、碰不到什麼」。
  4. 在紙上寫三句話：我下學期要教的一門課是＿＿／我最花時間的備課工作是＿＿／我手上已經有的教材是＿＿

做完長這樣：畫面上有回應，而且你紙上那三句寫完了。那三句話等一下就是送審稿的第一段。

加碼

  • 把你電腦裡放教材的那個資料夾，用 Claude 桌面版「加入專案」，讓它讀得到。
  • 問它：「這個資料夾裡有哪些東西？幫我列個清單。」
卡住了：裝不起來、登不進去，現在就舉手。今天上午所有需要帳號的段落都有紙本備援，你不會因為這個而空手回去。
U1

先搞懂你在花什麼：模型、思考力道、額度

09:30–10:10

這段是今天唯一的講述。放在最前面的原因很現實：不懂額度怎麼算的人，中午前就會把一天的量燒光，下午只能看別人做。

一、模型：挑貴的不一定比較好

模型什麼時候用感受
Opus要它想清楚才動手：規劃整門課的架構、把一堆散的教材整理成有邏輯的順序慢、貴、但想得深
Sonnet今天的預設。改講義、生簡報、跑腳本、大部分事情快、夠聰明、划算
Haiku機械性的事：改錯字、換格式、批次重新命名很快、很便宜

一句話：不確定就用 Sonnet。覺得它想得太淺再換 Opus。

二、思考力道（effort）：讓它想久一點

同一個模型可以調「要想多久再回答」。想得久＝答案好，但也＝慢、耗得多。

力道用在
低你已經知道答案，只是要它幫你打字
中一般備課工作，預設
高「這門課到底該怎麼排」這種真的需要它想的問題

三、額度：兩個桶子，會用完

桶子怎麼算用完會怎樣
5 小時額度從你第一句話開始計時，五小時內能用的量。時間到自動重來。暫停一下，等它回滿
週額度一整週的總量，週一重置這是真的會擋住你的那個

今天最要記住的一句：把「一次講很多次」改成「一次講清楚」。反覆丟半句話讓它猜，是燒額度最快的方式。另外，超額加購非常貴，不要順手按下去。

四、它太雞婆，可以直接停

它開始做你沒要它做的事，直接按停。停掉不會壞、不會弄丟東西，重講一次就好。今天請大膽地停它——會停的人學得比較快。

核心練習

  1. 找到你介面上顯示用量的地方，看一眼現在用了多少。
  2. 把模型切成 Sonnet。
  3. 故意問一個很大的問題（例如「幫我規劃一整學期十八週的課」），在它講到一半時按停。

做完長這樣：你知道用量在哪裡看，而且你已經按停過一次了。

加碼

  • 同一個問題，分別用「低思考」和「高思考」各問一次，比較兩個答案差在哪。
  • 想一想：你平常的備課工作裡，哪些其實用 Haiku 就夠了？
U2

接上插座：行事曆、雲端硬碟、Gmail

10:10–11:00

到目前為止它只是個聊天視窗。接上這三個之後，它才真的碰得到你的東西——這是今天第一個「有感」的時刻，也是上午的保底段。

核心練習・一次接一個，照順序

  1. Google 行事曆——最不會出錯，先拿一次成功經驗。接完問它：「我下週有哪些課？」
  2. 雲端硬碟——接完問它：「幫我找出我雲端硬碟裡跟＿＿這門課有關的檔案。」
  3. Gmail——接完問它：「幫我擬一封信給助教。」
    注意：它只擬草稿，寄出去這個動作永遠是你自己按。

三個都接好之後，用這句話一次串起來：

看我行事曆下週的課，把要用到的教材從雲端硬碟找出來，幫我擬一封信給助教說明要準備什麼。

做完長這樣：螢幕上出現一封信的草稿，內容提到了你真實的課名和真實的檔案名。

加碼

  • 請它把上學期的課程時間，整理成一張表寫進雲端硬碟。
  • 請它讀你信箱裡學生問過的問題，整理出「最常被問的五件事」——那就是你下學期該在第一堂課先講清楚的東西。
卡住了：如果授權畫面直接被擋掉、出現「管理員政策」之類的字，那是學校帳號的設定，換 wifi 或開手機熱點都沒有用——改用你的個人 Gmail 帳號登入就會過。這件事今天很可能會發生在一部分人身上，不是你操作錯。
U3

計時：一份簡報，你做多久、它做多久

11:00–12:00

今天唯一一段全班同時看錶的活動。你等一下要在送審稿裡寫「驗證方式」——那一格不能用形容詞填，要有數字。這個數字就是在這裡量出來的。

核心練習

  1. 先寫下來：你自己做一份十五頁的上課簡報，大概要幾分鐘？寫在紙上。
  2. 開始計時。把你手上一份現成的教材丟給它，請它做出簡報骨架。
  3. 接著請它做這三件事（這才是重點，不是「一鍵生成」）：
    ── 每一頁給你三個開場鉤子的備選
    ── 如果這章只剩二十分鐘，該砍掉哪幾頁
    ── 從舊教材裡挑出三張最相關的圖
  4. 停錶。跟你紙上那個數字對照。
這是我這門課第＿章的教材。幫我做出十五頁的簡報骨架；每一頁給我三個開場鉤子的備選；另外告訴我，如果這章只剩二十分鐘，你會建議砍掉哪幾頁、為什麼。

做完長這樣：紙上有兩個數字（你原本要多久／今天實際花多久），還有一份簡報骨架。那兩個數字下午要用。

加碼

  • 請它針對同一章，換一個對象重寫一次：「如果台下是完全沒有背景的大一新生，這十五頁要怎麼改？」
  • 把你自己教這章時最有效的那個例子講給它聽，請它幫你找出還可以放在哪幾頁。
要講清楚的分工：它會做結構、做取捨、對準受眾。但案例和教學經驗是你的，它生不出來。今天做出來的東西，交給學生之前你還要再調兩三輪——這句話請寫進你的送審稿。

U4

從「一次貼一個檔」到「讓它讀整個資料夾」

13:30–14:40

上午是單次的、用完就沒了。這一段開始做「可以重複跑的東西」——認證裡分「初階」和「專業」，分水嶺就在這裡：只生出一份簡報是初階，有一套可以每週重跑的流程才是專業。

核心練習

  1. 把你這門課的所有材料放進同一個資料夾（講義、投影片、作業、參考資料都丟進去）。
  2. 讓 Claude 讀整個資料夾，不是一個一個貼。
  3. 問它：「幫我完整讀一遍這個專案裡的資料，然後告訴我這門課現在的樣子。」
  4. 接著請它把「每週產生上課簡報」這件事寫成一份可以重跑的說明書。
請完整讀過這個資料夾裡的所有資料，然後把「從本週教材產生上課簡報」這件事，寫成一份下次可以直接重跑的步驟說明，存成一個檔案放在這個資料夾裡。

做完長這樣：資料夾裡多了一個檔案，內容是「下次要做同一件事，照這個做」。這個檔案就是送審要的「工具包」。

加碼

  • 請它把這份說明書改成可以套用在你另一門課的通用版。
  • 試著隔一段時間重新開一個新對話，只給它那份說明書，看它能不能自己跑完。跑不動就回去把說明書寫清楚——這個來回本身就是最好的練習。
卡住了：跑不起來就跟講師拿現成的檔案，改一行參數讓它動起來就好。會改比會寫重要。

14:40–16:00

這一段不需要帳號，人人都做得完。上午卡住的人，這裡一樣可以交出完整的東西。

核心練習

  1. 六段裡至少完成「題目」和「驗證方式」兩段——這兩段最難憑空補，其他段回家寫得出來。
  2. 寫完請 Claude 幫你看一遍：「這份稿子哪一段最弱？」

做完長這樣：一份六段稿，至少兩段是完整的句子而不是條列關鍵字。

送件前一定要知道的三件事：
① 專業級的授權同意書會公開在網站上——不要放沒授權的教材、學生個資、還沒公開的考題。
② 課程可以回溯前兩年，你過去教過的可能已經算數。
③ 送件是隨到隨審，但實際排程與必選科目請跟總辦確認，不要照這頁的說法送。
