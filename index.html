Git 是什麼？我又不寫程式，為什麼非裝不可？

Git 是一套「檔案的版本記錄器」。 你可以把它想成 Word 的「追蹤修訂」，但管的是整個資料夾： 誰在哪一刻改了哪個檔、改成什麼樣，全部留底，而且隨時可以退回去。

那 Claude 為什麼需要它？ 因為你等一下要做的事，是把整個資料夾交給它、讓它直接改你的檔案—— 不是貼一段字進聊天室而已。這件事的風險是顯而易見的：它可能改壞、可能改多。
所以 Claude 在動你的檔案之前，會先用 Git 把資料夾當下的樣子記下來。 改壞了，一句「還原」就回得去。沒有 Git，它就沒有這張安全網—— 所以它乾脆不讓你開始。

裝了會怎樣？不會怎樣。 它裝好之後就安靜待在背景，不會跳出來、不會佔你桌面、也不用註冊帳號。 你完全不需要學它怎麼用——今天全程不會叫你打任何一行 Git 指令， 都是 Claude 在背後自己用。

順帶一提，你今天在用的這個網站、還有等一下要下載的教材， 本身就是放在 Git 上管理的。這也是為什麼講師改一句話、你重新整理就看得到新版。

桌面版和網頁版差在哪？桌面版讀得到你電腦上的資料夾、也寫得回去。今天下午要做的事非它不可，網頁版做不到。
不想付錢、或刷卡卡住？先舉手，然後照樣往下做——今天每個單元都設計成「沒有帳號也交得出東西」。 只有「讀整個資料夾」「把檔案寫回電腦」那兩段需要付費方案。

  1. 打開 Claude 桌面版，登入。
  2. 左上角切到 </> Code，不要留在 Home（聊天）那一邊。
    這是今天最容易錯的一步。Home 是聊天，它讀不到你的檔案； Code 才能。兩邊長得很像，切錯的人到下午才會發現。
  3. 按 + New，然後挑一個你電腦上的資料夾。
    第一次用的人會看到 Select folder…； 挑好之後會問 Trust this workspace?，按 Trust Workspace。
    如果再跳出 Install Git，就是 Git 還沒裝——回上面那格裝好， 然後把 Claude 關掉重開。
  4. 確認輸入框上方出現兩個標記：一個是 Local，一個是你剛挑的資料夾名字。
    看到資料夾名字，才代表它真的接上你的電腦了。 如果那裡寫的是雲端環境的名字，它讀不到你的檔案。
  5. 隨便打一句話送出——「你好」就可以。要等到它真的回你，不是送出去就算。
    這一步只是確認這個 session 會動。不用想要問什麼。
  6. 再問它一句：「你現在讀得到我這個資料夾裡的東西嗎？列給我看。」
    它應該列得出檔案。列不出來，現在就舉手—— 這代表資料夾沒接上，不是你問錯。

做完長這樣：你在 Code 這一邊，輸入框上方有 Local 和你的資料夾名字，你打了一句話、它回你了， 而且它列得出那個資料夾裡有什麼。四件事都成立才勾起來。

① 它太雞婆的時候直接按停。停掉不會壞、不會弄丟東西，重講一次就好。今天請大膽地停它——會停的人學得比較快。

模型怎麼挑、思考力道、5 小時額度與週額度的完整說明，印在學習單最後當附錄，回去自己看。
卡住了：裝不起來、登不進去，現在就舉手。今天每個單元都有不需要帳號也交得出東西的路。你不會因為這個而空手回去。

這幾個「連接器」背後是什麼？——順便認識一個字：MCP

你剛才按的那三個按鈕，背後是同一套東西在運作，叫 MCP （Model Context Protocol，模型脈絡協定）。你不需要記這個縮寫， 但值得知道它在做什麼，因為這決定了 AI 能力的上限。

用一個比喻：MCP 是「AI 的萬用轉接頭規格」。
以前每個軟體要跟 AI 串接，都得各寫各的接法——你想讓它讀雲端硬碟， 得有人專門為「AI × 雲端硬碟」寫一套；想讀行事曆，再寫一套。 MCP 是把這件事標準化：只要照這個規格做一個轉接頭，任何 AI 都插得上。

所以「連接器」= 別人已經幫你做好的轉接頭。 Google Drive、Gmail、行事曆這三個是 Anthropic 官方做的，按一下就能用。 除此之外還有幾百個現成的（Notion、Slack、GitHub、資料庫…）， 而且任何人都能自己做一個——這才是重點。

為什麼這對你重要？ 今天你把「一個資料夾」給它，它就能改你的課綱。 如果哪天有人做出「義守授課計畫系統」的轉接頭， 它就能直接讀你在校務系統裡的課綱、甚至幫你填回去，不用你下載上傳。 講師今天發給你的那份課綱，就是用自己寫的轉接頭從系統抓下來的—— 43 位老師、346 門課，一次抓完。

你今天不用學怎麼做轉接頭。 知道「AI 的能力可以被擴充，而且擴充的方式是標準化的」就夠了。 下次你想「要是它能直接看到 ○○ 就好了」，那件事很可能已經有人做好了。

桶子怎麼算用完會怎樣

為什麼值得你也做一個

想一下你這門課現在的「網站」長什麼樣：

  • 系網上那頁課程介紹，可能是好幾年前填的
  • Moodle 每門課長得一模一樣，版面你改不動，而且學生沒登入就看不到
  • 要放一份補充資料，得挑一個「放在哪學生找得到」的地方——通常是找不到

一個自己做的課程頁可以是：學期中想到什麼就加什麼、學生一個連結就打開、版面你自己決定、 而且它是公開網址，可以直接當送審那格「作品連結」——比丟一個要登入才看得到的 Moodle 連結好用得多。

這是下一場的題目。今天不做——今天先把手上這門課翻新完。 但如果你今天五個練習都做完還有力氣，「幫我做一個這門課的課程頁」就是最好的加碼題。 做出來的東西今天就能上線。
