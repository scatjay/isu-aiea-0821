# 義守大學 AIEA 教師工作坊・實作站

2026-08-21（四）09:00–16:30　·　講師 楊智傑

學員入口網頁。GitHub Pages 靜態站，前面有一道**通行碼**（上課當天日期，四位數）。

## ⚠️ 這道通行碼不是資安措施

靜態站的密碼一定寫在原始碼裡，會按 F12 的人就繞得過去。它的作用是「擋住路過的人」，不是保護機密。

**所以這個 repo 永遠不放**：學員名單、任何個資、未公開的考題、未授權的教材。
那些東西在另一個 private repo，或根本不進版控。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 全部內容都在這一頁（通行碼閘 + 六個單元 + 自由探索菜單） |

單一檔案、無相依、無建置步驟。改完直接 push，GitHub Pages 幾分鐘後生效。

## 本機預覽

```
python -m http.server 8731 --directory .
```

開 http://localhost:8731 ，輸入通行碼。

## 設計前提（別改壞）

- **不分組**，依個人進度。每單元一題「核心練習」＋一題「加碼」。
- **課後不關站**——跟不上的人回家要能接著做完。
- 核心練習做完 = 湊得出 AIEA 送審六段的材料。
